# 🎖️ 新人高考总指挥部

高考内容统一门户 —— 把散落的**信息图 / 讲解课件 / 解题课件 / 记忆卡 / 打卡**收敛到一个可筛选的指挥台。

## 在线地址

| 平台 | 地址 |
|---|---|
| GitHub Pages | https://mcjc4.github.io/gaokao-hq/ |
| 备份 | 见部署状态表 |

## 核心设计

- **内容原地不动**：各课件/信息图仍留在原仓库，门户只做「登记 + 导航」，不迁移不改名。
- **单文件离线**：`index.html` 无任何外网依赖，KaTeX/样式/脚本全内联。
- **登记制**：新内容在 `MANIFEST` 数组加一条记录即自动收录、自动进筛选。

## 六大板块 / 分面标签体系

每份内容贴 **6 个维度**标签，筛选条件取交集即可任意维度组合查找：

| 维度 | 取值 | 说明 |
|---|---|---|
| 科目 | 语文/数学/英语/物理/化学/生物/思想政治/历史/地理/通用 | 固定枚举 |
| 形态 | 胶带信息图 / 讲解课件 / 解题课件 / 记忆卡 / 工具入口 | 固定枚举 |
| 章节 | 力学、运动学、电磁学… | 受控词表 |
| 层级 | 一轮基础 / 专题进阶 / 冲刺综合 / 通用 | 固定枚举 |
| 执行人 | 通用 / 陈昕言 / 陈梓涵 | 固定枚举 |
| 考点标签 | 连接体、相似三角形、匀变速… | 受控词表（多选） |

## ⚙ 标签管理

页面右上「⚙ 标签管理」可自行增减标签，无需改代码：

- 新增（相似标签提示合并）/ 重命名（全局替换）/ 合并 / 归档（可恢复）
- 每行显示「N 条在用」，词表内 0 条使用标灰、词表外被引用标橙
- ⬇ 导出备份 JSON / ⬆ 导入 / 📋 复制代码片段（渲染成 `MANIFEST` + `LEX_SEED` 常量，粘回文件即永久固化）

数据存本机 localStorage：`hq_lexicon`（词表）、`hq_archived`（归档）、`hq_patch`（内容改写层）、`hq_fav`、`hq_recent`、`hq_executor`。

> ⚠️ 换设备或清缓存前，请先点一次「导出备份 JSON」。
